Utako ships these programs and fonts unchanged, so it works without installing anything
else. Each keeps its own license; their source code is available at the addresses below.

mpv (local files and SoundCloud playback)
  License: GPL-2.0-or-later / LGPL-2.1-or-later (see mpv's Copyright file)
  Source:  https://github.com/mpv-player/mpv
  Windows build: https://github.com/shinchiro/mpv-winbuild-cmake
  macOS builds:  https://laboratory.stolendata.net/~djinn/mpv_osx/

yt-dlp (YouTube music videos, and finding Apple Music songs on YouTube for downloads)
  License: Unlicense
  Source:  https://github.com/yt-dlp/yt-dlp

zotify (Spotify downloads), in tools/zotify: frozen with PyInstaller together with Python and
the libraries it uses, listed with their versions in packaging/zotify/requirements.txt of
Utako's source (librespot-python, protobuf, pycryptodomex, requests, urllib3, certifi, Pillow,
mutagen, music-tag, zeroconf, tqdm, tabulate and a few more)
  zotify:            Unlicense, https://github.com/zotify-dev/zotify
  librespot-python:  Apache-2.0, https://github.com/kokarare1212/librespot-python
  Python:            PSF License, https://www.python.org
  PyInstaller:       GPL-2.0 with an exception for the programs it makes,
                     https://github.com/pyinstaller/pyinstaller
  The others keep their own licenses (MIT, BSD, Apache-2.0, MPL-2.0, HPND, GPL-2.0 for
  mutagen), found in each project's source.

Deno (runs YouTube's JavaScript for yt-dlp, which needs it to unlock video links)
  License: MIT
  Source:  https://github.com/denoland/deno

FFmpeg / ffprobe (saving and converting downloads, and drawing music videos)
  License: LGPL-2.1-or-later (Windows: LGPL build) / GPL (macOS static build)
  Source:  https://ffmpeg.org/download.html
  Windows build: https://github.com/BtbN/FFmpeg-Builds
  macOS builds:  https://github.com/eugeneware/ffmpeg-static

Inter (interface font)
  License: SIL Open Font License 1.1
  Source:  https://github.com/rsms/inter

Fredoka (the letters of the logo and the name "Utako", drawn as shapes)
  License: SIL Open Font License 1.1
  Source:  https://github.com/google/fonts/tree/main/ofl/fredoka
